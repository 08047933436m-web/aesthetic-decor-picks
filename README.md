# CosyHome — Проект партнерской витрины и автоматизации Pinterest

Этот проект — готовый стартовый комплект для заработка в связке **Pinterest + Сайт-витрина + Admitad (или любая CPA-сеть)** в нише *«Организация пространства и уют для дома»*.

---

## 📁 Структура проекта

* `index.html` — адаптивный мобильный сайт-каталог с фильтрами по категориям и карточками товаров.
* `products.json` — база данных товаров (названия, цены, описания, ссылки на фото и партнерские ссылки).
* `generate_pins.py` — Python-скрипт для автоматической генерации вертикальных пинов ($1000 \times 1500$ px) под Pinterest.
* `output_pins/` — папка с готовыми картинками для загрузки в Pinterest.

---

## 🚀 Быстрый старт

### 1. Как посмотреть сайт
Просто дважды кликните по файлу `index.html` или откройте его в любом браузере.  
Для проверки с локальным сервером можно запустить:
```bash
python -m http.server 8000
```
И открыть в браузере: `http://localhost:8000`

### 2. Как добавить свои партнерские ссылки Admitad
1. Зарегистрируйтесь в [Admitad](https://www.admitad.com/) (или любой другой сети, например, партнерке маркетплейсов).
2. Подключитесь к офферам: AliExpress, Яндекс Маркет, Ozon или Lamoda.
3. Сгенерируйте свои реферальные ссылки (Deeplink).
4. Откройте файл `products.json` и замените значения `"affiliateUrl"` на ваши партнерские ссылки.

### 3. Как сгенерировать новые пины
Если вы добавили новые товары в `products.json`, просто запустите:
```bash
python generate_pins.py
```
Скрипт скачает фотографии и сгенерирует стильные вертикальные макеты в папку `output_pins/`.

## 🌐 Как бесплатно опубликовать сайт в интернете (за 1 минуту)

Чтобы пользователи из Pinterest могли переходить на ваш сайт со смартфонов:

### Вариант через GitHub Pages (Бесплатно навсегда):
1. Создайте бесплатный репозиторий на [GitHub](https://github.com/).
2. Загрузите туда файлы `index.html` и `products.json`.
3. В настройках репозитория откройте раздел **Settings** $\rightarrow$ **Pages** $\rightarrow$ выберите ветку `main` и нажмите **Save**.
4. Через 30 секунд ваш сайт будет доступен по адресу вида: `https://ваш-логин.github.io/название-репозитория/`.

## 📌 Как публиковать в Pinterest (Правила для новичка)

1. **Создайте Business-аккаунт в Pinterest** (бесплатно).
2. **Создайте тематические доски:**
   * «Идеальный порядок на кухне»
   * «Уютная ванная комната»
   * «Организация дома: лайфхаки»
3. **График публикаций:**
   * Первые 2 недели: **не более 2–3 пинов в день**.
   * Со 2-й недели: 5–8 пинов в день.
4. **Оформление пина:**
   * **Заголовок:** Короткий и понятный (например: *«Как навести идеальный порядок в холодильнике: подборка контейнеров»*).
   * **Описание:** 2–3 предложения с ключевыми словами (*«прозрачные контейнеры для холодильника, организация кухни, эстетика дома, порядок на полках»*).
   * **Ссылка:** Ссылка на ваш сайт (или конкретный товар на сайте).
